# 早期探索记录

主线建立前的早期试验记录。ACC-local-L3 已被证明不可行，此页作为历史背景保留。

## KT 实验：集中 vs 分散

**实验 A：线程集中/分散策略**

目的：验证 chiplet-aware runtime 文献中的"线程集中/分散"启发在 CPU LLM 推理场景是否成立。

- 简单矩阵乘法：单线程工作集超过单个 L3 容量时，分散到多个 CCX 显著更快（5MB 工作集：集中 2996 ms vs 分散 648 ms）。
- `bench_moe`（qlen=4, hidden=7168, 14 线程）：集中 178 ms vs 分散 174 ms，差异很小，提示该 MoE 路径对 L3 不敏感。

**实验 B：限制可用 L3 大小**

- 56 线程 MoE 推理，每 CCX L3 从 1MB 到 16MB，L3 Miss Rate 始终在 85%~89%。
- 结论：权重远大于 L3，更像流式访问。

**实验 C：每 CCX 不同线程数**

- 线程数/CCX 从 1 到 7，L3 Miss Rate 基本维持在 85% 附近。
- 主要 miss 更像来自矩阵加载本身，不是线程间竞争。

## P0 函数级归因结论（2026-04-01）

来源：`test_results/PD_Test/Qwen3-30B-A3B/CLI_res/`

- decode 的高 L3 miss 不能写成"显式 attention 包装层主导"。
- decode 的 miss 延迟主要是本地 DRAM 路径，不是远端 DRAM 主导。
- prefill 的 miss 主路径比 decode 更靠近 vLLM 原生路径，能看到 attention/KV-cache 与 TP SHM 通信痕迹。
- prefill 不是"只有 attention"或"只有 MoE"，更像 TP SHM 通信 + 通用 GEMM + MoE + attention 共同出现在 miss 主路径。
